Наша документация размечена системой тегов для того, что бы ты мог быстро и консистентно вносить изменения вот как это выглядит сейчас, но возможно эта система тегов будет меняться и тебе нужно держать для себя актуальный метафайл с данными о тегах

#structure: - структура проекта
✅ #class: - классы
✅ #interface: - интерфейсы
✅ #api: - API endpoints
✅ #command: - команды
✅ #alias: - алиасы

То есть если ты меняешь какую-то часть документации а она помечена тегом, то ты можешь быстро найти все части документации с этим тегом и если изменения нужны и в этих частяз документации ты можешь их легко туда вносить
