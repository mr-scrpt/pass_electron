## 🔍 Методика проверки

### Шаг 1: Найти все блоки, которым нужны теги

Для каждого типа тега создать команду поиска:

#### 1. Деревья структур (нужен `#structure:`)
```bash
# Найти все ASCII деревья с src/
grep -n "src/domain/\|src/application/\|src/infrastructure/\|src/composition/\|src/presentation/" docs/**/*.md steps/**/*.md
```

#### 2. Определения классов (нужен `#class:`)
```bash
# Найти все определения классов в TypeScript блоках
grep -n "^class \|^export class " docs/**/*.md steps/**/*.md
```

#### 3. Определения интерфейсов (нужен `#interface:`)
```bash
# Найти все определения интерфейсов
grep -n "^interface \|^export interface " docs/**/*.md steps/**/*.md
```

#### 4. API endpoints (нужен `#api:`)
```bash
# Найти все HTTP методы в заголовках
grep -n "### GET \|### POST \|### PUT \|### DELETE \|### PATCH " docs/**/*.md
```

#### 5. Команды (нужен `#command:`)
```bash
# Найти все bash/shell команды
grep -n "npm \|pnpm \|yarn \|npx \|git " docs/**/*.md steps/**/*.md | grep -E '```|`'
```

#### 6. Алиасы импортов (нужен `#alias:`)
```bash
# Найти все импорты с @/
grep -n "from '@/\|from \"@/" docs/**/*.md steps/**/*.md
```
