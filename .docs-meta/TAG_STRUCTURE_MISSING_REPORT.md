## 🔍 Критерии качества

Для каждого дерева структуры нужно добавить:

1. **Теги директорий** - `#structure:путь/к/директории/`
   ```
   src/domain/                    #structure:domain/
   ├── resource/                  #structure:domain/resource/
   ```

2. **Теги файлов с классами** - `#class:ИмяКласса`
   ```
   │   ├── Resource.ts            #class:Resource
   ```

3. **Теги файлов с интерфейсами** - `#interface:ИмяИнтерфейса`
   ```
   │   ├── IRepository.ts         #interface:IRepository
   ```

4. **Выравнивание** - все теги должны быть выровнены для читаемости
